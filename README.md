## 仓库配置

- `.gitignore`：忽略本地密钥、常见依赖目录、缓存和构建产物。
- `.editorconfig`：统一 UTF-8 编码、换行和基础缩进规则；编辑器需支持 EditorConfig。
- `.gitattributes`：统一文本文件的 Git 换行方式。
- `CONTRIBUTING.md`：开发、验证和提交约定。
- `AGENTS.md`：Codex 等代码助手的协作约定。

## 配置与安全

不要提交密码、访问令牌、私钥或包含真实凭据的 `.env` 文件。
如果项目需要环境变量，添加仅含变量名和非敏感示例值的 `.env.example`，
并在这里说明用途。真实值通过云环境设置或本地配置提供。
