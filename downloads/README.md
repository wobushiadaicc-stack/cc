## 如何使用

1. 下载目录与阅读指南，以及三个公开全文包。
2. 将四个独立 ZIP 解压到同一个父目录，它们会合并到 `侧信道文献库_精选初筛_20261027` 文件夹。
3. 打开其中的 `00_优先阅读.md`，按推荐顺序开始阅读。
4. CSV 文件可用 Excel 打开，便于筛选论文和填写分区结果。

也可以直接从仓库首页点击 **Code → Download ZIP** 下载整个仓库，再解压 `downloads` 下的四个资料包。
